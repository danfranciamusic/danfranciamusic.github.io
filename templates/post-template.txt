# How to add a new post:
# 1. Copy this file into src/data/posts/ and rename it with a number prefix
#    higher than any existing post (e.g. 05-something.txt) -- posts display
#    newest-first, based on that number.
# 2. Fill in whichever fields apply. Posts have no title -- just delete any
#    field you don't need (text, link, image, image-alt, caption, video).
#    A post can be just an image, just text, text + a link, text + a video,
#    etc.
# 3. Images/videos referenced here must already be in public/ (for images)
#    or be a normal YouTube link (for video).
# 4. Run `node build.js` from the repo root, then commit + push.
